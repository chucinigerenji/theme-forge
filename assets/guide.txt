# 主题工坊 ThemeForge v2.0 · 使用说明

> 把「某个界面的一张图」换成你自己的图，然后打包成 `.mtz`，用 ThemeKit / 系统主题管理器直接打开即可。
>
> **第一次用请先看 App 里的《设置 → 新手教程》**（13 章 + FAQ，从概念讲到装机踩坑排查）；本文是精简版速查。
> 包名 `com.dsh.themeforge`，minSdk 24，targetSdk 34。

---

## 一、界面结构（v1.1 改版）

```
┌──────────────────────────────────────────────┐
│ 主题工坊                        [ ⚙ 设置 ]    │  ← 顶栏（无系统 ActionBar，不再重复标题）
│ 简单三步：选图片 → 打包 → 用主题管理器打开      │
├──────────────────────────────────────────────┤
│ 主题信息            我的主题              ▾   │  ← 默认折叠
│ 桌面壁纸 / 锁屏壁纸          未设置        ▾   │  ← 默认折叠，点了才展开
│ 状态栏                      未设置        ▾   │
│ 下拉通知栏                   未设置        ▾   │
│ 控制中心                    未设置        ▾   │
│ 桌面启动器                   未设置        ▾   │
│ 应用图标包                   未设置        ▾   │
│ 息屏显示 AOD                未设置        ▾   │
│ 锁屏样式                    未设置        ▾   │
│ 全局系统控件                 未设置        ▾   │
│ 系统应用换肤                 未设置        ▾   │
│ 主题预览图                   未设置        ▾   │
├──────────────────────────────────────────────┤
│ 还没有选图片。                  [打包主题] [打开/分享] │
│ 不选＝不改动，全部使用系统自带样式              │
└──────────────────────────────────────────────┘
```

* **默认全部折叠** —— 打开就是 12 行，点哪一行才展开哪一行的小项。
* 展开后：`范围`下拉（该分类下的模块/应用）、`整组套用一张图`、`清空本组`，然后是槽位列表。
* 每行右侧显示 **已选 N**（彩色）或 **未设置**（灰色），一眼看出动了哪些。
* 槽位行显示 **「输出 1880×3008（默认）」** 这样的实际输出分辨率；按钮：**选图 / 编辑 / 尺寸 / 清**。
* 展开后分类行按钮：**整组套用一张图 / 清空本组 / 本组尺寸**。

## 二、怎么用

1. 点开一个分类（例如「下拉通知栏」），点某个槽位的 **选图**，从相册/文件里挑一张图片。
2. 想精修就点 **编辑**：进入裁剪页，拖动白框选范围、拖四个角缩放；下方直接填 **宽 × 高**（可锁比例，一键取「默认 / 屏幕 / 裁剪原尺寸」），点保存。
2b. 也可以点 **尺寸**（槽位行）或 **本组尺寸**（分类行）单独设置某一项或整组的输出分辨率与缩放方式，不用先选图。
3. 每个界面互不影响，随时单独换图、单独清除。
4. 全部弄好后点 **打包主题**，弹出结果后可 **用主题安装器打开** 或 **分享**。
5. 之后再点 **打开/分享**，随时能重新打开上一次生成的包。

### 关于「不设置就是不改动」
没有上传图片的槽位**不会写进主题包**，系统继续用自带样式。
用「基础模板」时，模板里没被替换的内容也会原样保留。打包结果里会再提示一次。

### 关于基础模板
点「主题信息 → 选择基础模板 .mtz」，导入一套现成主题（例如你给的那份机甲爱丽丝）。
之后你上传的图会**逐项替换**模板里的同名文件，模板的锁屏样式、息屏、图标、各应用皮肤全部保留。
锁屏样式必须靠这种方式做——它依赖 `advance/manifest.xml` 布局脚本，没法从一张图推导。

## 三、设置页（⚙）

顶栏右上角 **⚙ 设置**（带一圈淡白描边，明显但不刺眼）。

| 区块 | 内容 |
|---|---|
| **软件主题色** | 8 个预设色（蓝/紫/绿/橙/红/青/石墨/玫红）+ **自己调色**：R/G/B 三条滑杆（滑杆按通道着色）、实时圆形预览、`#RRGGBB` 色值、`应用这个颜色`。只改软件配色，不影响生成的主题。 |
| **关于** | 版本、能力说明。 |
| **赞助支持**（页面最底部） | ¥0.99 / ¥9.99 两张收款码，下方写着 **「感谢您的支持，我会更快推出新软件的喵😋」**。 |

## 四、自动处理规则

| 情况 | 处理 |
|---|---|
| 目标文件名以 `.9.png` 结尾 | 按目标尺寸裁剪 → 四周补 1px 透明边 → 上边/左边 30%~70% 画黑色拉伸标记（生成合法九宫格） |
| 目标 ≥ 200×200（壁纸、窗口背景） | 等比缩放 + 居中裁切铺满目标尺寸 |
| 目标是小图标（电池、信号、图标包） | 等比缩放完整放入，居中、保留透明 |
| 目标是 `.webp` / `.jpg` | 按对应格式编码（WebP 在 API 30+ 用无损） |
| 换过壁纸 | 自动同步生成 `preview/preview_wallpaper_0.jpg` 等预览图 |

### v1.9 新增（解决「改了分辨率装上去还是错」）

**根因：不是分辨率没生效，是方向没对上。**

平板 / 折叠屏横竖屏**共用同一张壁纸**。你在竖屏时把壁纸做成 1880×3008（竖），之后把设备横过来用，
系统会按横屏比例把这张竖图**居中裁切**——只留中间一条，于是看起来「装错了」。

这一版做了三件事：

1. **壁纸默认尺寸跟随当前方向**：启动、旋转屏幕、以及点「打包」的那一刻都会重新读取屏幕分辨率，
   未自定义的壁纸永远按当前方向输出。
2. **尺寸对话框新增「横竖对调 ↺」**：一键把宽高换过来（1880×3008 ↔ 3008×1880）。
3. **方向不符会提前警告**：当你要的尺寸比例和当前屏幕差 18% 以上时，会明确告诉你
   「方向是反的，系统会居中裁掉上下/左右」，并提示当前屏幕是横屏还是竖屏。

> 判断建议：**常用的那个方向**去做壁纸。两个方向都要用的话，把主体放中间、四周多留一点，
> 或者干脆做一张接近正方形的图（横竖都会被裁，但都裁得不多）。

### v1.8 新增
1. **全屏看图的背景改成「变深 + 虚化」**：不再是全透明，图片浮在压暗并模糊的背景上，看得更清楚（Android 12+ 走系统背景模糊，低版本至少保证变深）。
2. **基础模板支持 .7z**：
   - 主题作者常把 `.mtz` 打包成 7z，甚至做成**自解压 exe**（文件名是 `.7z`，实际是 PE 壳 + 7z 数据）。
   - 现在两种都能直接选，App 会自动跳过 PE 壳、找到 7z 数据、把里面的 `.mtz` 取出来当模板，之后的预览 / 换图 / 打包流程完全一样。
   - 也支持把文件直接放到 `Android/data/com.dsh.themeforge/files/base-template.7z`，下次打开 App 会自动解包。
   - 用的是纯 Java 的 7z 解码（Apache Commons Compress + XZ for Java），不需要额外的 native 库。

### v1.7 新增
**点缩略图就能全屏看图。**
- 点任意槽位左边的缩略图 → 全屏显示这张图。
- 窗口背景是**透明的**：图片直接浮在当前屏幕上面，PNG 的透明通道会原样保留，
  方便判断状态栏图标、开关背景这类图实际叠在手机界面上的效果。
- **右上角有个 ✕**，点它或点屏幕上任意位置都能关掉。
- 显示的是原图（自己传的图直接读原文件；模板里的图从 `.mtz` 里现抽），不是那条 128px 的小缩略图。

### v1.6 新增
**选了基础模板后，界面上直接显示模板里的原图。**
- 没上传自己图片的槽位，缩略图会显示模板里那张图，副标题标注 **「· 模板图」**，按钮变成「换成自己的」。
- 这样一眼就能看出：这个位置模板长什么样、哪些你已经覆盖、哪些还是模板原样。
- 模板图是从 `.mtz` 里**流式抽出来的缩略图**（不落盘、不整包解压），首次展开某个分类时读一下，之后就缓存在内存里。
- 顶一下「清」把自定义图删掉，会自动回落到模板图。
- 换模板或移除模板后，预览会重新加载。

### v1.5 新增
1. **把「范围」讲清楚**：范围就是主题包里的资源目录，同一张图通常有
   **浅色 / 深色 × 标准(xxhdpi) / 超清(nxhdpi)** 四份，文件名一模一样——这是 MIUI 主题的结构，不是重复。
   现在范围名字直接写成「浅色 · 标准 xxhdpi」「深色 · 超清 nxhdpi」，卡片上还有一行说明。
2. **「整组套用一张图」新增勾选「同时写入同名其它范围（深色 / 超清）」**：
   勾上之后，同名图片在浅色/深色、标准/超清里一次全部写掉，不用改四遍。

### 范围（浅色 / 深色 / 密度）到底是什么

| 范围 | 对应目录 | 什么时候用 |
|---|---|---|
| 浅色 · 标准 xxhdpi | `res/drawable-xxhdpi/` | **大多数手机日常显示用的就是这一份**，优先改这个 |
| 浅色 · 超清 nxhdpi | `res/drawable-nxhdpi/` | 更高密度屏幕用的同图另一份 |
| 深色 · 标准 xxhdpi | `nightmode/res/drawable-xxhdpi/` | 开「深色模式」时显示的那份 |
| 深色 · 超清 nxhdpi | `nightmode/res/drawable-nxhdpi/` | 深色 + 高密度 |
| 浅色/深色 · 电池 raw | `(nightmode/)res/raw-xxhdpi/` | 电池图标单独放在 raw 目录 |

只改浅色 → 白天变了、夜间还是原样；两个都改才彻底。用上面那个勾选框可以一次搞定。

## 六、自动处理规则（v1.2 更新）

| 情况 | 处理 |
|---|---|
| 槽位设了自定义尺寸 | 按自定义 W×H + 所选缩放方式输出 |
| 壁纸未设尺寸 | 按当前设备屏幕分辨率输出 |
| 其他槽位未设尺寸 | 用内置参考尺寸（就是样例主题里那张图的原始尺寸） |
| 目标以 `.9.png` 结尾 | 先缩放，再四周补 1px 透明边 + 上/左 30%~70% 黑色拉伸标记（合法九宫格） |
| 目标是 `.webp` / `.jpg` | 按对应格式编码（WebP 在 API 30+ 用无损） |

## 七、已知限制

1. **锁屏样式**需要基础模板，不能靠一张图生成。
2. 字体 / 铃声 / 开机动画 / 动态壁纸：样本主题里没有，暂未覆盖。
3. 默认只写浅色（`res/`）；深色变体在同分组的「深色」条目里单独上传。
4. `uiVersion=17` 对应澎湃OS 3.0；MIUI 14 / HyperOS 1–2 需要改小。
5. 导出的主题包放在 `Android/data/com.dsh.themeforge/files/out/`；点「用主题安装器打开」会自动授予读取权限，无需手动找文件。
