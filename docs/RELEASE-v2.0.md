# 主题工坊 ThemeForge v2.0

小米 / 澎湃OS 主题（`.mtz`）制作工具 —— 给每个界面喂一张图，生成可直接安装的主题包。
5088 个图片槽位全部标好了「这张图是干什么的、要多大、是不是九宫格」。

## ✨ 主要功能

- **11 个界面分类 / 93 个分组 / 5088 个槽位**，默认全部折叠，点开才加载
- **逐项换图**：每个槽位独立的 选图 / 编辑 / 尺寸 / 清，互不影响
- **裁剪 + 分辨率**：拖动裁剪框、四角缩放；填宽×高、锁比例、一键取「默认 / 屏幕 / 原图 / 横竖对调」
- **缩放方式**：拉伸铺满 / 等比裁切 / 完整放入，可逐项或整组设置
- **九宫格自动生成**：目标是 `.9.png` 时自动补 1px 边框 + 黑色拉伸标记
- **整组套用**：一张图铺满一组，可勾选「同时写入同名其它范围」一次写上 浅色/深色 × 标准/超清
- **一键清空本项** / **5088 槽位全局搜索** / **全屏看图**（背景变深虚化）
- **基础模板**：导入 `.mtz` / `.7z` / 自解压 exe，模板没被替换的内容原样保留，界面直接显示模板原图
- **壁纸尺寸跟随设备方向**，横竖屏不符会提前警告
- **软件主题色**：8 个预设 + RGB 自己调色
- 内置《新手教程（13 章 + FAQ）》《使用说明》《MTZ 文件功能对照表》

> 核心原则：**不设置就是不改动**。没上传图片的位置不会写进主题包，系统继续用自带样式。

## 📦 安装

1. 下载下面的 `ThemeForge-v2.0.apk`
2. 手机上点击安装（会提示「未知来源」，允许即可；出现「未查询到 ICP 备案」选「继续安装」）
3. 需要 **Android 8.0+**；实测澎湃OS 3.0（Android 16）正常

安装包信息：

```
文件    ThemeForge-v2.0.apk
大小    788601 字节（约 770 KB）
sha256  cdb97648edf0271851edbc669fecaffeabf7d4014169f9975660ed7d1b24629d
签名    APK Signature Scheme v2 + v3（自签名，minSdk 24）
```

> ⚠️ 本应用使用自签名证书。如果以后用别的证书重新编译，**必须先卸载再装**，否则会提示签名冲突。

## 🚀 快速上手

1. 展开「桌面壁纸 / 锁屏壁纸」→ 点【选图】
2. （可选）点【编辑】裁剪、点【尺寸】调分辨率 —— 注意横竖屏方向
3. 点底部【打包主题】→【用主题安装器打开】

生成的文件在 `Android/data/com.dsh.themeforge/files/out/`，用 ThemeKit 或系统主题管理器加载即可。

## ⚠️ 已知限制

1. **锁屏样式**依赖 `advance/manifest.xml` 脚本，无法由一张图推导，要改必须导入基础模板
2. 不支持字体 / 铃声 / 开机动画 / 动态壁纸
3. 默认只写浅色，深色模式要另外改「深色」那一份
4. 按 `uiVersion=17`（澎湃OS 3.0）打包，MIUI 14 / HyperOS 1~2 可能不适配
5. 平板 / 折叠屏横竖屏共用一张壁纸，方向不对会被系统裁切（App 会警告并可一键横转竖）
