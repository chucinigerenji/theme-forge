# 主题工坊 ThemeForge v2.1

小米 / 澎湃OS 主题（`.mtz`）制作工具 —— 给每个界面喂一张图，生成可直接安装的主题包。
**11 个分类 / 104 个分组 / 5088 个图片槽位**，每个槽位都标好了「这张图是干什么的、要多大、是不是九宫格」。

> 本次更新的主题是 **「不用再满手机找素材」**：主题库一次存多套主题，
> 选图时可以直接从**任何一套已保存的主题**里取图。

## ✨ v2.1 新增

### 1. 主题库（多套主题统一管理）

入口：「主题信息 → 主题库 / 基础模板」

- **＋ 导入**：`.mtz` / `.7z` / 自解压 exe，**支持一次多选**；
  同一个文件重复导入不会占两份空间（内容 MD5 去重）
- 每条主题可 **设为打包基础模板 / 重命名 / 导出分享 / 删除**，
  当前模板那条挂「当前模板」标签，一键切换
- 老版本那一个基础模板文件会自动搬进库里，升级不丢数据

### 2. 从主题库取素材（核心新功能）

做主题时不用再去找原始图片 —— 在任意界面项上点 **选图 / 换图 / 换成自己的** →
选「从主题库取素材」，就能从**主题库里的任何主题**挑图：

- 顶部一排药丸按钮切换来源，**「全部主题（N个）」会把所有主题的素材合在一起**；
  当前基础模板那个带 ★
- 分类下拉 + **跨全部分类搜索**（搜 `battery`、`通知`、`icon` 等）
- 列表只显示该主题里**真实存在**的图片，带缩略图
- 普通图片按**原始字节搬运、不重编码**（画质零损失）；
  `.9.png` 会先去掉自带的 1px 边，避免打包时叠成 3px 双层边
- 几百 MB 的主题第一次扫某分类会慢（页面显示秒数），扫过一次即缓存，切换秒开

### 3. 打包后可直接存为模板

生成成功后弹窗里点 **「保存为模板」**，把刚做好的主题收进主题库，
下次可以直接在它基础上继续改，或把它当素材来源。

### 4. 内置《使用手册》重写（20 章 / 约 780 行）

从「更新日志」改成真正的参考手册：`.mtz` 结构、主界面每个元素的含义、
裁剪与尺寸、范围（浅色/深色 × 密度）、**十一个分类逐个说明**、
主题库与取素材、打包内部流程、装机三种方式、还原、FAQ 14 条、术语表。

## 🐞 v2.1 修复

- **取素材后主界面不更新**：`Store` 的「哪些槽位有图」缓存原来每个实例一份，
  取素材是在另一个 Activity 里写盘，主界面回来读旧缓存就以为没选图
  （表现成「点了使用但界面毫无变化」）。改成进程级共享缓存。
- **切换来源主题被静默丢弃**：扫描大主题期间，切主题/分类/搜索的请求会被直接丢掉，
  导致列表一直停留在第一个主题的结果上（表现为「只能拿到当前模板那个主题的图标」）。
  改为代号（gen）版本控制，新请求作废旧结果。
- **扫描期间长时间占用对象锁**：`index()` 整个方法加锁，几百 MB 的主题扫起来
  会让其他线程全部阻塞。改成独立的扫描锁。
- **缩略图缓存上限写死 400**：主题库里主题一多会吃掉几百 MB 内存，改为可配（取素材页用 160）。
- **不规范九宫格漏判**：原来只靠像素特征判断 `.9.png`，作者做的不规范九宫格会漏判，
  打包时被再补一层边、变成 3px 双层边。现在文件名已明说 `.9.png` 就直接裁外圈。
- **主题库操作对话框点不动**：`AlertDialog` 同时用 `setMessage` + `setItems`，
  在澎湃OS 上操作项整个不渲染。改成自定义布局对话框，主操作改一键直达。

## 📦 安装

1. 下载下面的 `ThemeForge-v2.1.apk`
2. 手机上点击安装（会提示「未知来源」，允许即可；出现「未查询到 ICP 备案」选「继续安装」）
3. 需要 **Android 8.0+**；实测澎湃OS 3.0（Android 16）正常

安装包信息：

```
文件    ThemeForge-v2.1.apk
大小    825843 字节（约 806 KB）
sha256  b543d83b6be4abdddd65c94a198bdc8a8f38d22a0f583989de38f15cf48ba181
签名    APK Signature Scheme v2（自签名，minSdk 24）
```

> ⚠️ 本应用使用自签名证书。如果以后用别的证书重新编译，**必须先卸载再装**，否则会提示签名冲突。

## 🚀 快速上手

纯新手流程：

1. 展开「桌面壁纸 / 锁屏壁纸」→ 点【选图】，挑一张背景
2. （可选）点【编辑】裁剪、点【尺寸】调分辨率 —— 注意横竖屏方向
3. 点底部【打包主题】→【用主题安装器打开】

想做得更完整：

1. 主题库 → **＋ 导入** 一套现成主题 → **设为基础模板**
   （锁屏样式、息屏显示、图标、各应用皮肤就都有了，你只改想改的那几张图）
2. 展开分类，没替换的槽位会**直接显示模板里的原图**，一眼看出该改哪几个
3. 某个界面想要别的主题里的图标 → 点【选图】→【从主题库取素材】→ 挑一张 →【使用这张图】
4. 【打包主题】→【用主题安装器打开】

生成的文件在 `Android/data/com.dsh.themeforge/files/out/`，用 ThemeKit 或系统主题管理器加载即可。

## ⚠️ 已知限制

1. **锁屏样式**依赖 `advance/manifest.xml` 脚本，无法由一张图推导，要改必须导入基础模板
2. 不支持字体 / 铃声 / 开机动画 / 动态壁纸
3. 默认只写浅色，深色模式要另外改「深色」那一份（或用「同时写入同名其它范围」）
4. 按 `uiVersion=17`（澎湃OS 3.0）打包，MIUI 14 / HyperOS 1~2 可能不适配
5. 平板 / 折叠屏横竖屏共用一张壁纸，方向不对会被系统裁切（App 会警告并可一键横转竖）
